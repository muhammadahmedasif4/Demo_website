# Demo-Website

## 📌 About

This project is a **demo website** created to showcase modern web design, clean layout, and responsive user interface. It is built to demonstrate basic frontend development skills including structure, styling, and navigation.

## 🚀 Features

* Responsive design for different screen sizes
* Clean and simple user interface
* Easy navigation
* Organized layout and styling

## 🛠 Technologies Used

* HTML
* CSS
* JavaScript

## 📂 Project Purpose

This website was developed for learning and practice purposes to improve frontend development skills and understand how a real website is structured.

## 📸 Preview

You can run the project locally to see the website in your browser.

## ▶️ How to Run

1. Download or clone the repository
2. Open the `index.html` file in any web browser
3. Explore the website
